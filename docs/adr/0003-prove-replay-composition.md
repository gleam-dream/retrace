# Prove replay composition with two applications

<a id="adr-0003"></a>

On 2026-10-10 the user accepted the independent review's next increment: repair
client delivery hazards and prove the complete composition with another app.
This extends ADR 0002 without changing the wire format or portable core.

An optional Lustre companion owns reconstruction and frame lifetime. Applications
supply native types, codecs, reducers, views and presentation. A fixed inventory
viewport and recorded membership resize exercise different policies. The default
viewer remains replaceable and its reader uses absolute cursors before API freeze.

Client storage and transport are explicit adapters so browser builds do not
require a native plugin. Pending and durable capacity are separate bounds.
Overload stops capture visibly rather than silently skipping part of a session.

Lazy seeking, live following, session-list pagination and throughput tuning are
later work. Application-owned build recipes remain the recommendation. There is
no builder package, publication or upstream PR in this increment.
