# Example interface

The example extends the prior Lustre membership prototype's native-style controls.
Use a quiet near-white canvas, dark ink, a restrained green accent and platform
sans-serif text. Content leads: navigation, the membership interaction surface,
and a distinct searchable session viewer. No promotional sections or invented metrics.

Use a sidebar on wide windows and a compact top navigation on phones. Keep buttons
at least 44px high, labels explicit, focus visible and content scrollable when it
cannot fit. Keep live and recorded state visibly distinct. Error, loading, pending,
empty and success states occupy the same predictable status region. Respect reduced
motion. Inspector styling belongs to the separately pinned Time Travel dependency.
