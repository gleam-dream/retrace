# Retrace example

The user requested a reusable session-replay package with a shared Lustre example
running in a browser and Tauri. Earlier mobile examples established a native-feeling
membership application. This example carries that functional visual vocabulary
forward rather than introducing a marketing identity.

Audience: the package author and developers evaluating recording and replay.
Task: generate interactions, see local/delivered status, find a session by user,
and replay the application state without running its effects.

The first release is a local developer tool with real PostgreSQL and S3-compatible
storage. It has no hosted authentication or pixel/native-screen recording claim.
Platform: responsive webview, browser and Tauri. A Rust platform-information
command supplies the native effect example. Neutral backgrounds, native controls,
clear hierarchy and direct status copy are implementation choices for this scope.
